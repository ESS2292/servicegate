Service image pin agreement guides

How to keep Docker Compose, GitHub Actions service containers, and tests on the same Postgres or Redis major.

These guides are public but pre-launch, and should not be indexed. Facts about official docs, cited issues, commits, and Stack Overflow statistics were checked on 10 November 2026.

Do your Compose file and GitHub Actions agree on Postgres?

A Compose pin and a workflow service image can drift independently. Documented cases include a 12-vs-14 split and a migration that bumped both files together.

When Testcontainers and Compose pin different Postgres majors

A public Compose file can move to Postgres 16 while tests still start 15.5, including a case where a shared-variable pull request was closed without merging.

pg_dump failed because the client and the service were different majors

When CI upgrades the Postgres service, a host client or an older pg_dump can refuse to talk to it. Official docs also show why a health check belongs on the service.
