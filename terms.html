Terms

Last updated: November 10, 2026 (America/New_York). These terms describe the planned packaged sale of ServiceGate. Checkout is not live.

The product

ServiceGate 0.1.0 is a Node.js CLI sold as a one-time $19 USD packaged release with MIT-licensed source included. You are buying a packaged release and docs convenience, not exclusive proprietary rights to the code. MIT permission includes use, modification, and redistribution subject to the license notice.

Honest limits

ServiceGate is a consistency gate. It is not a digest pin, not a Dockerfile style linter, and does not look up Docker Hub or an end-of-support calendar. Parsing of workflows and Compose files is best-effort, not a full YAML 1.2 implementation. Testcontainers detection is limited to string literals in files that import a Testcontainers library.
